# Bobcat Webelos - Complete Materials & Prep List

**Meeting Date:** Saturday, October 11, 2025  
**Setup Time Needed:** 30-45 minutes before meeting  
**Location:** Indoor  
**Meeting Length:** 75 minutes

---

## COMPLETE SHOPPING/GATHERING LIST

### General Supplies
- [ ] Webelos handbook (for leader reference)
- [ ] 18+ pencils/pens
- [ ] Name tags (if needed)
- [ ] Hand sanitizer or wet wipes
- [ ] First aid kit
- [ ] Whistle (for attention/rotation signals)
- [ ] Watch or timer

### Station 1: Scout Law Detective
- [ ] 36 index cards (3 sets of 12)
- [ ] 3 permanent markers (to make cards)
- [ ] 3 tables or floor spaces for card layout

### Station 2: Teach Sign, Salute & Handshake
- [ ] Coordinate younger den attendance (Lion/Tiger/Wolf/Bear) OR plan role-play pairs
- [ ] Optional: Print 9 fundamentals worksheets (from `Cub-Scout-Fundamentals-Reference.md`)
- [ ] 9 pencils/pens (if using worksheets)
- [ ] 1 reference sheet showing proper Cub Scout sign/salute/handshake (print or poster)
- [ ] Clear space for pairing practice

### Station 3: Denner Brainstorming
- [ ] 9 sheets of paper (8.5x11) - cut into 18 half-sheets
- [ ] 18 pencils/pens
- [ ] 1 folder or envelope (to collect finished papers)

### Full Group Activities
- [ ] 2 large posterboards (22" x 28")
  - One for Den Code of Conduct
  - One for Denner Responsibilities
- [ ] 8-10 markers in various colors
- [ ] **Optional:** Colored paper, stickers, decorations for posters

### Station Signage
- [ ] 4 signs or papers labeled:
  - "Station 1: Scout Law Detective"
  - "Station 2: Teach Fundamentals"
  - "Station 3: Denner Ideas"
  - "Station 4: Silent Line Up"

### Station 4: Silent Line Up
- [ ] Clear open space (at least 15 feet)
- [ ] No materials needed!

---

## PRE-MEETING PREP TASKS

### 1 Week Before
- [ ] Send meeting reminder to parents
- [ ] Request 4 parent volunteers for stations
- [ ] Confirm younger den participation (if using cross-age teaching)
- [ ] Order/gather all materials

### 2-3 Days Before
- [ ] Confirm parent volunteers
- [ ] Print station instruction sheets for helpers
- [ ] Create station signs
- [ ] Print fundamentals reference sheet (if not already)

### Day Before
- [ ] Pack all materials in bins/bags
- [ ] Print optional fundamentals worksheets (if using)
- [ ] Confirm younger den attendance or prepare role-play plan

### Day of Meeting - 45 Minutes Before Start

#### Task 1: Create Scout Law Cards (20 minutes)
- [ ] Make 3 identical sets of 12 index cards each (36 cards total)
- [ ] Write ONE Scout Law point per card:
  1. Trustworthy
  2. Loyal
  3. Helpful
  4. Friendly
  5. Courteous
  6. Kind
  7. Obedient
  8. Cheerful
  9. Thrifty
  10. Brave
  11. Clean
  12. Reverent
- [ ] Organize cards into 3 sets in separate envelopes or rubber bands

#### Task 2: Prep Teaching Station (5 minutes)
- [ ] Lay out fundamentals reference sheet where visible
- [ ] Print optional worksheets (or decide verbal only)
- [ ] Place pencils (if using worksheets)
- [ ] Identify clear area for pairing practice

#### Task 3: Prep Denner Station (5 minutes)
- [ ] Cut 9 sheets of paper in half (18 half-sheets)
- [ ] Gather 18 pens
- [ ] Have folder ready to collect papers
- [ ] Place at Station 3 area

#### Task 4: Prep Full Group Materials (5 minutes)
- [ ] Label 2 posterboards:
  - "Our Den Code of Conduct"
  - "Denner Responsibilities"
- [ ] Set out 8-10 colorful markers
- [ ] Keep in a safe area until needed

#### Task 5: Set Up Station Areas (5 minutes)
- [ ] Mark 4 station locations with signs
- [ ] Ensure stations are spread out (at least 10-15 feet apart)
- [ ] Verify tables/floor spaces are adequate
- [ ] Ensure Station 4 has clear open space (at least 15 feet)

## QUICK CHECKLIST - Day of Meeting

**Bring from home:**
- [ ] All materials (see shopping list above)

- [ ] Test that markers work
