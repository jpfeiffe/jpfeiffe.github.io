# Station 1: Magic 1089 Number Trick

**Station Duration:** 5 minutes per rotation (3 rotations total)  
**Group Size:** 10-12 scouts per rotation  
**Location:** Table with materials

---

## Your Role

You'll lead scouts through an amazing math trick where you predict the answer before they even start! This is a fun "magic" activity that keeps a large group engaged and demonstrates that math can be mysterious and cool.

---

## Materials Provided

- [ ] Slips of paper (25-30 total)
- [ ] Pencils (10-12)
- [ ] **Pre-folded paper with "1089" written inside** (prepared before meeting!)
- [ ] Table or flat surface

**CRITICAL:** Make sure the "1089" prediction paper is visible on the table BEFORE scouts arrive, but they can't read what's inside!

---

## Activity Instructions

### Before Scouts Arrive at Your Station (30 seconds)
1. Place the folded "1089" prediction paper in a visible spot on the table
2. Have blank paper slips and pencils ready
3. Smile and look mysterious!

### When Scouts Arrive (30 seconds)
1. Welcome: "Hi everyone! Welcome to Station 1: The Magic 1089!"
2. Point dramatically to the folded paper: "Before you even started, I wrote down a prediction. Let's see if I got it right!"

### The Trick - Do It Together (3 minutes)

**Step 1: Choose a Number**
"I need a volunteer to pick a special number!"
- Ask one scout to call out any **3-digit number** where all digits are different
- Examples that work: 274, 531, 892, 146
- Examples that DON'T work: 999, 747, 111 (digits repeat)
- If they pick a repeating number, say: "Close! But all three digits need to be different. Try again!"
- Write their number BIG on a slip of paper so everyone can see

**Step 2: Reverse It**
"Now let's reverse those digits!"
- Example: 274 becomes 472
- Write the reversed number below the first number

**Step 3: Subtract**
"Write the LARGER number on top, and subtract the smaller number."
- Example: 472 - 274 = 198
- Help with the math if needed (it's okay to narrate: "2 minus 4... we need to borrow...")
- Write the answer clearly
- **IMPORTANT:** If the result is only 2 digits (like 99), add a zero in front (099)

**Step 4: Reverse Again**
"Now reverse THIS number!"
- Example: 198 becomes 891
- Write it below

**Step 5: Add**
"Add these two numbers together!"
- Example: 198 + 891 = 1089
- Let scouts help with the math

**Step 6: THE REVEAL!**
"What did you get? [Wait for them to say 1089]"
"Now... let's see what I predicted BEFORE we started!"
- Have a scout open the folded paper
- Everyone sees "1089"!
- "MATH MAGIC! It ALWAYS equals 1089!"

### If You Have Time (1 minute)
"Want to try with a different number? Pick another!"
- Let another scout choose a number
- Go through steps 1-6 quickly
- It will be 1089 again!

### Wrap-Up (30 seconds)
"That's the magic of math! No matter what 3-digit number you start with (as long as digits are different), you'll always end up at 1089! Pretty cool, right?"

---

## Tips for Success

✅ **Speak Loudly and Clearly:** You have 10-12 scouts; everyone needs to hear!

✅ **Help With Math:** Not all scouts are comfortable with borrowing/carrying. It's okay to walk through it step-by-step.

✅ **Build Suspense:** Make the reveal dramatic! Pause before opening the prediction.

✅ **Keep Moving:** You only have 5 minutes, so keep the energy up!

✅ **It's Okay to Mess Up:** If someone miscalculates, just redo that step. The trick always works if you follow the steps correctly.

---

## Common Questions & Answers

**Q: "Why does it always equal 1089?"**  
A: "That's the magic of math! When you follow these exact steps with any 3-digit number (digits different), it ALWAYS lands on 1089. Math has patterns we can count on!"

**Q: "Can we try with a 4-digit number?"**  
A: "Great question! This trick only works with 3 digits, but there are other math tricks for different numbers!"

**Q: "What if I want to try it at home?"**  
A: "Absolutely! Just remember: 3 digits, all different. Then reverse, subtract, reverse, add. You'll get 1089 every time!"

**Q: "Did you really know it would be 1089?"**  
A: "Yes! I learned this math trick, and it ALWAYS works. That's the cool thing—math is predictable!"

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Scout picks repeating digits (777) | Politely ask for different number: "All digits need to be different!" |
| Math error during subtraction | Redo that step together; narrate the borrowing clearly |
| Result is 2-digit number | Add a zero in front (25 becomes 025) before reversing |
| Running out of time | Skip second example; move to wrap-up |
| Too much time left | Do a third example or let multiple scouts pick numbers |

## Rotation Transition

**When Time is Called (at 5-minute mark):**
1. "Great job, mathematicians! Time to rotate!"
2. Direct Group to their next station
3. Reset materials for next group (fold up a new "1089" prediction if you used the original, or just refold it)
4. Welcome the next group with the same energy!

## The Math Behind It (If You're Curious)

This trick works because of mathematical properties:
- When you reverse and subtract a 3-digit number (with different digits), you always get a multiple of 99
- When you reverse that result and add, it always equals 1089
- It's a beautiful example of patterns in mathematics!

---

## Quick Reference: The Steps

1. Pick 3-digit number (digits all different)
2. Reverse it
3. Subtract (larger minus smaller)
4. If result is 2 digits, add 0 in front
5. Reverse the result
6. Add them together
7. Result is always **1089**!

---

**Example Walkthrough:**

Starting number: **531**  
Reversed: **135**  
Subtract: 531 - 135 = **396**  
Reverse: **693**  
Add: 396 + 693 = **1089** ✨
